# Your resumes go here

Drop your tailored resume PDFs (and cover letters, if any) in this folder — one per role track
is common if you're searching multiple tracks (see `questions.md` item 4a). Nothing in this
folder is tracked by git except this file (see the root `.gitignore`), so your resumes never
leave your machine unless you choose to share them.

If you're running the Claude Code chat workflow (see root `CLAUDE.md`), point Claude at this
folder when asked and it'll read the PDFs to help fill out `answers.md`.
